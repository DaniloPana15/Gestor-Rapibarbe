☁️ Sincronización en la Nube Gratis

Como GitHub Pages es una web estática, conectala a una base de datos gratuita (JSONBin.io) para que todo lo que cargues en el celular aparezca al instante en la compu.

¿Cómo activarlo en 2 minutos? (100% Gratis)

  1. Entrá a jsonbin.io y creá una cuenta gratis con tu Gmail.
  2. En el menú izquierdo entrá a API Keys y copiá tu X-Master-Key.
  3. Pegala acá abajo y tocá "Crear Nube Automática". ¡Listo!
